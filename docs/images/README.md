# Screenshots Directory

This directory contains the screenshots and images used in the WindowOperatorUI documentation.

## Adding Screenshots

When adding screenshots:

1. Use descriptive filenames (e.g., `main-screen.png`, `window-selection.png`)
2. Optimize images for web (compress when possible)
3. Use PNG format for UI screenshots
4. Keep resolution reasonable (1280x720 or similar)

## Required Screenshots

The following screenshots are referenced in the main README:

- `logo.png` - Project logo (200px recommended width)
- `main-screen.png` - Main application interface
- `window-selection.png` - Window selection with crosshair tool
